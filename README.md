## Get started
1. Clone this project to your local machine:
``` zsh
cd ./some/local/directory
git clone https://github.com/stephen-gilbert-cko/checkout-google-postman-workspace.git
```

2. Open [Postman](https://www.postman.com/downloads/)

3. Go to **Workspaces** > **Create**

4. Fill out details, selecting to set up the workspace **From a local folder**

5. Navigate to **Local items** (📦 icon at the top of the left sidebar)

You should now see the collection and environment.
